LET'S UNDERSTAND

What is Function Composition?

Function composition is the process of applying one function to the result of another function.

(f ∘ g)(x) = f(g(x))

This means we apply g first and then apply f to the result.

The final output is written as f(g(x)).

REAL LIFE CONNECTION

Function Composition Around Us

Function composition isn't only found in textbooks. It can describe processes that happen in everyday life.

🛍️

Shopping

Imagine buying an item that first receives a discount and then has tax added.

Original Price → Discount → Tax → Final Price
🌡️

Temperature

A temperature can be converted from Celsius to Fahrenheit and then used in another calculation.

Celsius → Conversion → Fahrenheit
🚗

Travel

Distance can be converted into fuel consumption and then into the cost of a journey.

Distance → Fuel → Cost
